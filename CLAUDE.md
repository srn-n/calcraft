# CLAUDE.md

All project context, house rules and the release process are in **[AGENTS.md](AGENTS.md)**. Read it
first; it's the single source of truth shared by every AI agent working on this repo.

The key rules, repeated:
- Never commit or push. Samiur does that himself.
- Every update ships with a Markdown record:
  - `docs/releases/<version>.md` for app releases, written from `docs/releases/_TEMPLATE.md`.
  - `docs/changes/YYYY-MM-DD-<topic>.md` for anything else.
  - Then update `AGENTS.md` §9 and §10.
- No third-party characters or brands.

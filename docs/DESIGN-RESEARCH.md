# Calculator Design Research — 100 references

The goal is to make a simple tool deeply interactive. Arithmetic is solved, so the UI is the product.

**Method.** I catalogued 100 calculators: physical products, native apps, notepad and natural-language tools, open-source projects, web tools, and Dribbble/Behance concept shots. For each one I wrote down the single idea worth taking. Products are judged by their known, documented design. Concept shots are grouped by the pattern they share, because individual Dribbble shots go offline too often to cite one by one.

Legend: **→** the idea we take.

## A. Physical calculators (industrial design) — 1–25
1. **Braun ET66 (Rams/Lubs, 1987)** → round convex keys, colour only to signal meaning (yellow `=`), and nothing else decorative.
2. **Braun ET22 / ET33** → a dark body with light keys works too; the hierarchy comes from shape, not colour.
3. **HP-12C** → gold/blue shift-key labels printed above the keys: one key, three functions, which keeps a panel dense but learnable.
4. **HP-15C** → a landscape layout gives a long display row for long expressions.
5. **HP-35 (1972)** → the first pocket scientific calculator; a red LED display has a warmth an LCD lacks.
6. **HP-41C** → user-assignable keys, i.e. personalisation predating apps.
7. **Casio fx-82 / fx-991** → the "natural textbook display" shows fractions and roots as they are written, which is the gold standard for readable expressions.
8. **Casio SL-300 / solar desk calculators** → the grey seven-segment LCD with a visible solar strip; the look reads as "calculator" to everyone.
9. **Casio CA-53W watch** → a calculator in 6 mm of keys; extreme constraint makes the design memorable.
10. **Casio VL-1 (VL-Tone)** → a calculator that is also a synthesiser: sound as delight. **→ per-theme key sounds.**
11. **TI-30Xa** → cheap, chunky and readable; ergonomics beat beauty for daily use.
12. **TI-84 Plus CE** → multi-line history on the screen; arrow keys scroll back through it.
13. **TI-Nspire** → a touchpad cursor plus documents, so calculations become notes.
14. **Sharp EL-W516** → the "WriteView" multi-line display shows the input and the answer together.
15. **Sharp Compet (1964)** → the first transistor calculator; nixie-tube glow as a visual reference.
16. **Sinclair Executive (1972)** → a slim black slab with red LEDs; minimal and luxurious.
17. **Sinclair Cambridge** → small keys, big personality; tactile dimples.
18. **Curta (mechanical)** → the crank as interaction: the physical act of calculating is satisfying.
19. **Olivetti Divisumma 18 (Bellini)** → soft rubber nipple keys; tactility as design language.
20. **Olivetti Logos 27** → a printing tape: history as a physical ribbon. **→ paper-tape history.**
21. **Canon Pocketronic** → a thermal tape, i.e. the receipt as UI.
22. **Teenage Engineering OP-1 / EP-133 K.O. II** → tiny caps, engraved mono labels, one orange accent, playful toy-grade precision.
23. **Nothing Phone (Glyph/dot matrix)** → dot-matrix type, red accent, OLED black.
24. **Muji desk calculator** → beige and silent; the absence of branding is the brand.
25. **Citizen SDC-888** → a tilted display and big keys; the accountant ergonomics of a GT (grand total) key.

## E. Web and open-source calculators — 69–78
69. **Google Search calculator widget** → a familiar 4×5 grid, `Ans` key, and Rad/Deg toggle visible at all times. **→ DEG/RAD always visible.**
70. **Microsoft Calculator (open source, GitHub)** → its engine and UI are separated cleanly. **→ our engine/UI split.**
71. **Uno Calculator** → the Windows calculator on the web and mobile, showing one codebase on all platforms.
72. **Omni Calculator** → 3,000 single-purpose calculators: a specific tool beats a general one for tasks.
73. **calculator.net** → dense but trusted; proof that utility beats looks for some users.
74. **Excel status bar** → select numbers to see their sum: calculation without asking.
75. **JS30 / CSS-Tricks calculator demos** → classic first projects; they show how few calculators care about state edge cases.
76. **Codrops creative calculators** → experimental motion; physics springs feel alive.
77. **Neumorphism.io-era calculators** → soft UI looks great, but contrast fails; use with care.
78. **Retro skeuomorphic CSS calculators** → texture via CSS gradients and SVG noise, no images.

## F. Dribbble/Behance concept patterns — 79–100 (grouped by recurring idea)
79. **Full-bleed numerals (e.g. Hikmet Atceken)** → generous spacing and restrained colour for hierarchy.
80. **Neumorphic savings calculator (Mariana Konstantynova)** → trend aesthetics attract users, and a soft theme should be offered as an option.
81. **Slider-driven mortgage calculators (Paramveer)** → sliders replace typing for ranges. **→ tip slider.**
82. **Three colour groups (Ramona Tăbuşcă)** → digits, operators and actions each get a group, and the groups survive light/dark modes.
83. **LLT mortgage dashboard** → the result is the hero; type size equals importance.
84. **Glassmorphism calculators** → frosted keys over a colourful backdrop; only one glass layer.
85. **Brutalist calculators** → thick borders, offset hard shadows, loud type.
86. **Bauhaus calculators** → circle/square/triangle keys in primary colours.
87. **Cyberpunk HUD calculators** → chamfered corners, scanlines, monospace telemetry.
88. **Terminal/CRT calculators** → phosphor green, glow, scanline flicker.
89. **Blueprint calculators** → grid paper and technical annotations.
90. **8-bit/arcade calculators** → pixel fonts and score counters; gamification fits.
91. **Swipe-up history sheets** → history as a bottom sheet with drag.
92. **Expression-above, answer-below displays** → live preview of the answer while typing.
93. **Big "=" key** → a double-height or double-width equals for the primary action.
94. **Animated result count-up** → numbers roll into place; delight on `=`.
95. **Particle/confetti on milestones** → rewards for streaks or easter eggs.
96. **Haptic-labelled keys** → different vibration for digits versus operators.
97. **Theme switcher as swatches** → preview the theme before you choose it.
98. **Converter-in-calculator** → unit chips under the display.
99. **Dark OLED minimal** → only an accent colour lights; the black background saves battery.
100. **Gamified maths trainers** (Elevate, Lumosity maths games) → short timed rounds, streaks and combos; skill games keep people coming back. **→ games built on the real keypad.**

## Patterns we adopt
- **The answer previews live** while typing (29, 14, 92), and `=` commits with motion (94).
- **Smart parenthesis key** (30) plus ghost closing brackets, so expressions are never "Error" for a missing `)`.
- **Coloured expression tokens** (52, 55): numbers, operators, functions and brackets each get a colour.
- **Swipe to delete, swipe for history, long-press to clear all** (26, 43, 91).
- **Keyboard-first on desktop, command palette, Enter copies** (31, 34, 65).
- **Paper-tape history** with search and tap-to-reuse (20, 39, 41).
- **Theme catalogue** where each theme is a real object or movement, previewed as swatches (1–23, 38, 84–90, 97).
- **Per-theme sound and haptics** (10, 96).
- **Focused tools beat menus** (28, 72, 98): Tip & Split, Units, Percent.
- **Games played on the calculator itself** (100): the keypad is the controller.
- **Private and offline, no permissions** (56): no network calls, no tracking.

## Patterns we reject
- Neumorphism as a default (77): its contrast fails WCAG; it ships only as an option, with contrast fixed.
- Stacked glass layers (84): one blur layer at most, because blur is costly on low-end GPUs.
- Photo backgrounds loaded from the internet (old v4 Glass): replaced by CSS/SVG generated art.
- Indigo-to-purple gradients and other generic, templated styling.

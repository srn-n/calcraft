# Bouncy Calculator 1.0.2 (versionCode 7)

Released to the closed test track after 1.0.1. Web (Vercel) and Android ship from the same push.

## What changed

### 1. No more theme "blink" when the app starts, closes or comes back
- **Cause:** on phones the calculator body (`--device`) fills the screen, and in several themes it is a
  different colour from the backdrop (`--bg`): TE, Station Clock, Concrete, Mission Control, Voyager and
  Solar LCD. The loading screen sat on `--bg`, and the open/leave/return fades faded the whole `.app`,
  so the backdrop flashed through for a moment.
- **Fix:**
  - `src/ui/splash.js` `matchScreen()`: on phones the splash copies the app body's real background
    (solid colour or gradient). Translucent bodies such as Liquid Glass keep the backdrop.
  - `src/styles/splash.css`: on phones the fades animate the app's *children*, never its background.
  - `src/ui/themes-ui.js` `screenColour()`: the Android system bars and saved window colour use the
    colour that is actually on screen.
  - The splash animation now starts only once fonts are ready, so the typeface never swaps mid-animation.
- **Verified:** all 24 themes frame by frame (cold start, then leave with Back, then return) showed
  0 off-colour frames. Mission Control still shows about 30 ms of backdrop on the very first *web* paint,
  before any script runs; in the app that moment is hidden behind the system splash.

### 2. Sound follows the phone's sound mode; vibration is independent
- Android: `MainActivity.Bridge.soundAllowed()` returns false when the ringer is on silent or vibrate.
  `src/fx/sound.js` asks on every key press, so changing the mode with the volume keys applies at once.
- Vibration ignores the phone's sound mode on purpose (the in-app Vibration setting controls it).
- Settings notes: Sound says "Follows your phone: muted on silent or vibrate" (app only). Vibration says
  "Independent of your phone's sound and vibration settings."

### 3. Paste button next to DEG/RAD
- `index.html` `#pasteChip`; `src/main.js` `pasteText()` is shared with Ctrl+V and uses the same strict
  `sanitizePaste` clean-up.
- Android reads the clipboard through the new `Bridge.paste()` (first 400 characters). The web uses
  `navigator.clipboard.readText()`, which may ask for permission.
- Known, existing behaviour: letters are kept (function names such as `sin`), so pasting plain words
  shows an error when evaluated, same as before.

### 4. Tools → Bills (new)
- `src/ui/bills.js`: 11 presets (Electricity, Water, Gas, Internet, Phone, Rent, Insurance, Council rates,
  Streaming, Car rego, Other) with themed SVG icons.
- Frequencies: weekly, fortnightly, monthly, quarterly, 6-monthly, yearly and one-off.
- Upcoming list sorted by due date, with "Overdue N days", "Due today" and "In N days · date" badges.
- Mark as paid rolls the due date to the next cycle (month-end safe: 31 Jan becomes 28 Feb) and keeps the
  last 12 payments. One-off bills become "Paid".
- Totals: due this month (overdue and repeats included), monthly average, overdue count.
- Per-bill notes plus a general Notes box. Currency picker: $ € £ ¥ ₹ ৳.
- Dates use three themed pickers (day, month, year), not the system date dialog.
- Delete needs a second tap.
- Data is saved with the tools state and validated on load by `cleanBills()` in `src/core/schema.js`:
  60 bills max, real dates only, known kinds and frequencies, length caps.
- **Bouncy sub-tab switching:** the new tool springs in from the side you're heading to
  (`tool-in-left` / `tool-in-right`), and the tapped tab pops. This animation is separate from the
  Calc/Tools/Games slide.
- Tests: `tests/bills.test.js` covers due dates, month-end and leap-year handling, totals and the
  saved-data validation. 136 tests in total.

## Files touched

- Web: `index.html`, `src/main.js`, `src/fx/sound.js`, `src/ui/splash.js`, `src/ui/themes-ui.js`,
  `src/ui/tools.js`, `src/core/schema.js`, `src/styles/base.css`, `src/styles/splash.css`.
- New: `src/ui/bills.js`, `tests/bills.test.js`, `docs/releases/1.0.2.md`, `docs/PROJECT-NOTES.md`.
- No new permissions: VIBRATE is still the only one, and there is still no INTERNET permission.

# Bouncy Calculator 1.0.3 (versionCode 8)

## Previous releases (short summary)
- **1.0.2 (code 7)**, full report in `docs/releases/1.0.2.md`:
  - **Theme blink fixed:** on phones, the splash and the open/leave/return fades now use the colour
    the app actually shows. All 24 themes checked frame by frame, 0 flashes.
  - **Sound follows the phone's sound mode:** muted on silent or vibrate. Vibration is independent.
  - **Paste button** next to DEG/RAD (Android uses a native clipboard bridge).
  - **Tools → Bills:** presets, due dates and overdue badges, mark as paid with history, monthly totals,
    notes, a currency picker, themed date pickers, and saved data validated on load.
  - **Bouncy sub-tab switching** in Tools. 136 tests.
- **1.0.1 (code 6):**
  - Every theme got its own key sound.
  - Vibration now uses the motor directly, with Sound and Vibration levels.
  - Themed unit dropdown, and font licences shown in an in-app sheet.
  - Fixed: Tools tabs collapsing on Percent, splash text overlap, and fast theme switching. VIBRATE
    permission added.
- **1.0.0 (code 5):**
  - First closed-test build (package `com.simplymadestudio.bouncycalculator`).
  - Smoother launch and exit animations, edge-to-edge system bars, and Back handling.

## What changed

### Themes: 28 in total
- **Removed:** Solar LCD. Anyone who had it selected is moved to Neon Tokyo automatically
  (`RENAMED` in `src/themes.js`).
- **New classic theme:** Neon Tokyo (`neon`). Smoked-glass keys, hot-pink and cyan glow, Space Grotesk.
- **New Exclusive themes**, with original characters by Simply Made Studio drawn on the keys:
  | id | Name | Character |
  |---|---|---|
  | `astro` | Nova in Orbit | Nova, a little astronaut (stars on keys, rocket on AC) |
  | `ronin` | Neon Ronin | Kage, a samurai with a crescent helm (katana marks, hanko seal) |
  | `pinkpop` | Pink Pop | Starla, a pop star with heart shades (sparkles, heart) |
  | `kitten` | Mochi Kitten | Mochi, a sleepy kitten (paw prints, yarn ball) |
- How the art works: the SVGs live in `src/ui/theme-art.js`. `applyArt()` puts them in CSS custom
  properties (`--art-char`, `--art-op`, `--art-ac`) through the CSSOM, which the CSP allows. The CSS in
  `themes.css` (under `[data-exclusive]`) places the character on the `=` key and in the header (with a
  little wave), a motif on the operator keys, and an accessory on AC. There are no image files.
- The theme picker has an **Exclusive** section (with badges) above **Classic**.
- Each new theme has its own key sound (`src/fx/sound.js`).
- **Not built, on purpose:** the requested Spider-Man, Wolverine and Barbie themes. These are protected
  characters and brands (Marvel/Disney and Mattel). Using them without a licence breaks Google Play
  policy and risks app removal, so original characters were made instead.
- Store assets: `04-solar-lcd.png` was replaced by `04-nova-in-orbit.png`, and `05-themes.png` was
  re-shot with the Exclusive section. `LISTING.md` now says 28 themes and mentions the characters and
  Bills.

### ☰ menu reorganised
- The theme sheet holds only themes.
- The ☰ button opens a new **Menu** sheet (`#menuSheet`, `createMenuSheet()` in
  `src/ui/themes-ui.js`):
  - Settings: Sound and Vibration levels, thousands separators, gesture hints, reduce motion.
  - Help & about: feedback, privacy, terms, font licences, credit.
- The command palette is still available with Ctrl+K, and from it you can open themes or settings.

### Bills: faster taps
- Opening or closing a bill's editor now swaps only that row in place. Before, the whole list was
  rebuilt, which replayed every row's animation and could jump the scroll position.
- Rows bounce in only when Bills first opens. A saved bill gets a small pop.

## Tests
- `tests/themes.test.js` (new) checks:
  - 28 unique, storage-safe theme ids;
  - every theme has CSS and its own sound;
  - the exclusive art is static SVG only;
  - lcd maps to neon.
- 140 tests pass in total.
- A frame-by-frame blink check of the 5 new themes found 0 off-colour frames.
